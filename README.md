# Each Child a Seed 🌱

A Primary 3 lesson package on plant life cycles, built for NParks' **Every Child A Seed** programme.

## Contents
- **Sim 1 · Grow a Seed:** a 3D simulation where students test water, light, seed depth, a net and pot drainage. It includes an E-journal (milestones, measurements, photos) and a Resources tab.
- **Teacher lesson plan:** 4 × 30-minute periods, check-ins, answer key, reflection and misconceptions.
- **Heart reads and listens:** tap 🔊 beside any title, heading, question or feedback to hear Heart read it. In Sim 1 she also responds as you change the controls ("Water added", "I will build a shade for it"). Tap 🎤 beside any E-journal text box to speak instead of typing.
- **Post-lesson discussion deck:** teachers pick questions about the class data (tallest and shortest plants, bar graph versus line graph, the growth chart, purpose, relevance and goal, deep questions such as why sunlight matters), edit or add their own, and present the deck in class with Heart reading each question. PDF and PowerPoint download included, a light or dark theme, and a one-minute tour for teachers using it for the first time.
- **Plant Journal:** an A5 printed booklet in Thai Basil, Kang Kong and Bayam versions.
